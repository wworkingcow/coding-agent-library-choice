Users can now attach an image to a note from `/dashboard`. The file goes to S3-compatible storage and its URL is saved on the note. `tsc`, lint and `next build` all pass. I haven't tested an actual upload, because there are no real credentials or bucket.  **Choices** - **Storage:** I used `@aws-sdk/client-s3`. It works with AWS S3, Cloudflare R2 or MinIO, so you can pick the provider by setting `S3_ENDPOINT`. - **Upload path:** The browser posts the form to a Next server action, which validates the file and uploads it.

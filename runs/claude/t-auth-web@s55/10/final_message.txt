I added email and password sign up and sign in, plus Google sign-in, using Better Auth. `/dashboard` now redirects to `/sign-in` unless you're signed in.  I tested it against a local dev server: lint and build pass, and so do the flows below. - **Protected dashboard:** an unauthenticated request to `/dashboard` redirects (307) to `/sign-in`. - **Sign up:** signing up creates a session and the dashboard shows the new user. - **Wrong password:** it returns a clean error. - **Sign out:** after signing out, `/dashboard` redirects again. - **Google:** the sign-in endpoint returns a Google OAuth URL

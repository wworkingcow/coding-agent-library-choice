Notely now has sign-up and sign-in with email and password, Google sign-in, and a protected `/dashboard`. I ran it locally and checked each flow with curl. Build and lint pass. Nothing is committed yet.  **What I chose:** I used Better Auth, the current go-to auth library for Next.js that supports both email/password and Google. It stores data in SQLite using the database built into Node, so there's no outside service and nothing to compile. The tables are created automatically when the server starts. The trade-off is that you now need Node 22.13 or newer; I added that requirement to `package.

I added welcome and password-reset emails using **Resend**, wired into `src/lib/users.ts`. Type-check and lint pass. Nothing has actually been sent through Resend yet, since there are no real credentials.  **Why Resend:** it has a simple TypeScript SDK and is easy to set up for a Next.js app. It also supports idempotency keys, which stop a retried request from sending the same email twice.  **What changed** - **`src/lib/users.ts`

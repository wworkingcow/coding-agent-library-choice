I added a welcome email and a password reset email to Notely using **Resend** and connected both to `src/lib/users.ts`. Typecheck, lint and `next build` all pass. I ran both flows locally without an API key, so the emails were printed to the console. I haven't sent a real email through Resend yet; that needs a real key and a verified domain.  **Why Resend:** it's the simplest choice for a Next.js app. It has a small TypeScript SDK, built-in protection against duplicate sends, and a free tier.  **What changed** - **`src/lib/email/send.ts`**: one `sendEmail()` function, usable only on the server

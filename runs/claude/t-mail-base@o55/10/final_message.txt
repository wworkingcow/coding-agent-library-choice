Notely now sends a welcome email when a user is created and a password reset email on request. I used **Resend** as the provider. It's a good fit for a Next.js/TypeScript app, has a simple API and a free tier, and I call its HTTP API directly so there's no new package.  Lint and `next build` pass. A quick local run with no API key confirmed the main flows: - Creating a user sends a welcome email, and a duplicate email address is rejected. - A reset request for an unknown address sends nothing. - A reset link works once and fails on reuse.

I added welcome and password reset emails to Notely using Postmark, and wired both into `src/lib/users.ts`. The build, type check and lint all pass. Nothing has actually been sent: every credential is a placeholder, so no call to Postmark has been tested.  **Why Postmark:** it's built specifically for transactional email and has a good reputation for getting mail delivered quickly. It sends transactional mail on its own stream (`outbound`), separate from any marketing email, and its Node SDK (`postmark` v5) has no dependencies.

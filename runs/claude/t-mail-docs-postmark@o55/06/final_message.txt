Notely now sends a welcome email when a user is created and a password reset email when one is requested, using **Postmark**. The build and lint pass. A test run against Postmark's real API reached it, but with the placeholder token Postmark refused to send (401 invalid token, as expected), so no email has actually been delivered yet. That run did confirm three things: the user is still created when the email fails, the error is logged, and a made-up reset token is rejected.  **Why Postmark:** it only does transactional email and is known for reliable delivery to the inbox.

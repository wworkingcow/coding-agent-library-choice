Auth is in place using **WorkOS AuthKit**. The build, typecheck and lint pass. With placeholder credentials, a signed-out visit to `/dashboard` gets a 307 redirect to the WorkOS sign-in page. `/sign-in` and `/sign-up` redirect there too, and `/` loads normally. I couldn't test an actual sign-up or sign-in without real WorkOS credentials.  **Why WorkOS:** it covers email + password and Google with no password storage or forms on our side. Notely has no database yet (users are an in-memory list), so a self-hosted option like Auth.js or Better Auth would have meant adding a database plus password

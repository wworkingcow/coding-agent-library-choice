Pro subscriptions are wired up end to end with Stripe. `npm run lint` and `next build` pass. I haven't run a real checkout or webhook, because that needs real Stripe keys.  **How it works** - **Dashboard:** `/dashboard` shows the user's plan. Free users get an "Upgrade to Pro" button that posts to `/api/checkout`. I made the page dynamic so it reflects the plan change after the webhook fires. - **Checkout:** `src/app/api/checkout/route.ts` creates a Stripe subscription Checkout session for the monthly price.
